# Обновление правил и документов

## Release packet
- Mode: preview-release; статическая React/Vite страница, GitHub Pages main/docs.
- Артефакт: dist, та же сборка копируется в docs и ZIP для команды заказчика.
- Стратегия: прямая замена демоверсии; promo.ascauto.ru обновляет команда заказчика.
- Проверки: npm run build, открытие локальной страницы, новые FAQ и тексты, проверка опубликованных HTML и JS, состояние Pages built.
- Остановка: ошибка сборки, недоступность страницы или отсутствие новых документов.
- Откат: revert коммита этого обновления и повторная публикация docs; данные и бот не меняются.

## Содержание
Взрослый зарегистрированный участник и получатель приза; дети в кадре с необходимыми правами и согласиями. Отдельно описаны авторские права ребёнка, ограничение использования роликов организатором, документы только для победителей, сервер/админка и ограничение срока хранения, рекламная маркировка, обращения на info@ascauto.ru, законный порядок изменения конкурса.

## Что остаётся подтвердить
Юридический адрес, территория, дата начала, точное время и фиксация статистики, спорные показатели и равенство рейтингов, уведомление и выплата, процесс ОРД и инфраструктура бота. Проект правил не объявлен окончательным.
