# DONGFENG Creator Cup — React

Копия актуальной страницы блогеров: React 18 + Vite.

## Запуск
```sh
npm install
npm run dev
```

## Сборка
```sh
npm run build
npm run preview
```
Результат — dist/. Можно разместить на любом статическом хостинге, в том числе в подпапке GitHub Pages.

## Структура
- src/App.jsx — компоненты страницы, состояние калькулятора, отблеск логотипов и появление карточек.
- src/styles.css — исходное оформление, адаптивность и reduced-motion.
- src/assets/ — локальные изображения, логотипы и шрифты.

Регистрация: https://t.me/Ascauth_bot. Ссылка на активности гостей сохранена. React-копия размещена отдельно от HTML-страницы.

GitHub Pages публикует папку docs из ветки main. После изменений выполните npm run build и скопируйте содержимое dist в docs перед коммитом.
